THE BIG IDEA

Sorting puts values in order.

Comparison sorts repeatedly inspect values and reorganize them until every item is in ascending order. These three algorithms are excellent for learning algorithmic thinking, even though faster options are usually preferred for large collections.

ALGORITHM 01

Bubble Sort

Bubble Sort compares neighboring values. When the left value is larger, it swaps the pair. Large values gradually “bubble” toward the end.

  1. Compare adjacent values.
  2. Swap them if they are in the wrong order.
  3. Repeat passes until no swaps are needed.

def bubble_sort(values):
    for end in range(len(values) - 1, 0, -1):
        swapped = False
        for index in range(end):
            if values[index] > values[index + 1]:
                values[index], values[index + 1] = values[index + 1], values[index]
                swapped = True
        if not swapped:
            break
    return values

ALGORITHM 02

Selection Sort

Selection Sort scans the unsorted portion to find its smallest value, then places that value at the next sorted position.

  1. Start at the first unsorted position.
  2. Find the smallest remaining value.
  3. Swap it into the current position.

def selection_sort(values):
    for start in range(len(values) - 1):
        minimum = start
        for index in range(start + 1, len(values)):
            if values[index] < values[minimum]:
                minimum = index
        values[start], values[minimum] = values[minimum], values[start]
    return values

ALGORITHM 03

Insertion Sort

Insertion Sort grows a sorted section on the left. Each new value shifts larger values right until it can be inserted in the correct position.

  1. Choose the next value as the key.
  2. Shift larger values in the sorted section right.
  3. Insert the key in the gap.

def insertion_sort(values):
    for index in range(1, len(values)):
        key = values[index]
        position = index - 1
        while position >= 0 and values[position] > key:
            values[position + 1] = values[position]
            position -= 1
        values[position + 1] = key
    return values
