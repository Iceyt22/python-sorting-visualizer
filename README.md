# Python Sorting Studio

A static, interactive learning site for Bubble Sort, Selection Sort, and Insertion Sort in Python.

## Features

- Plain-language explanations and properties for three comparison sorts
- Valid Python implementations for every algorithm
- Interactive step-by-step visualizer
- Start, pause, reset, step, speed, and fresh-array controls
- Responsive layout, keyboard-visible focus, reduced-motion support, and a skip link
- No dependencies or build process

## Open locally

Open `index.html` in a modern browser.

## Project files

```text
index.html
css/styles.css
js/app.js
```

## GitHub Pages

1. Push this folder to a GitHub repository.
2. Open the repository settings.
3. Select Pages.
4. Deploy from the `main` branch and the root folder.

The published site will be available at a GitHub Pages URL after deployment completes.
